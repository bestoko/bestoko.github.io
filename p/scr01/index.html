三星 SCR01 入手简单折腾

可能是颜值最高的5G随身WIFI

Dec 15, 2024

公司的网络最近经常抽风，逛小绿书无意间发现了三星有给日本运营商定制过一批随身WIFI，颜值特别高，遂入手配合联通副卡过渡使用。

外观与配置

(家附近联通基站信号不好，因此图上是4G，在公司5G使用顺畅)

接着过一遍完整参数与支持的频段

MediaTek Dimensity 720 (MT6853)

Android 11 with OneUI 3.0 (w/o Google Play Services)

2.5GB RAM

32GB Internal Storage

WiFi 5

5000mAH Battery

5.3" (1480x720) LCD Display

Network bands:

5G: n28 / n41 / n77 / n78

4G: LTE FDD: B1 / B3 / B17 / B18 TDD: B41

Disabled Bands that can be enabled:

4G: B7 / B38

其实相较于国内很多随身WiFi的配置，这个性价比并不高，但耐不住颜值戳中我，放着当个日历摆件也好看，黄鱼入手。

解除SIM 锁 开启5G频段

  • 点击 关于 >> 状态 >> 手机号码，快速点击10次
  • 点击 10 次，进入 DRParser Mode，此时依次输入 *#0011#
  • 进入到 service mode，再次点击右上角，点击一次 back，再次点击 key input
  • 这时输入 Q 并确认，在此界面等待大概一分钟后，会进入到主菜单界面
  • 点击 [2] UE SETTING & INFO » [1] SETTING » [1] PROTOCOL » [9] NR » [2] allow list control » [2] allow list off，显示 APPLY success，
  • 右上角菜单，点击两次 back 回到上层目录，点击 [1]nr5g sa/nsa mode control » [1] sa/nsa enable，按照提示重启设备

allow list off 即运营商锁，关掉之后我们才可以使用默认日本运营商之外的卡

sa/nsa enable 默认disable，开启后则可以使用5G

设置APN

通信设置 >> APN 里 如图设置即可使用国内移动联通的卡上网。

电信则需要安装第三方桌面，在安卓原生设置里设置更多APN 参数

  1. 名称：ctlte
  2. apn：ctlte
  3. 用户名：ctwap@mycdma.cn
  4. 密码：vnet.mobi
  5. MCC：460
  6. MNC：03
  7. apn类型：*
  8. apn协议：IPV4&IPV6
  9. apn漫游协议：IPV4&IPV6

使用感想

耐用，耐用，还是tm的耐用！

在阉割了很多不必要的硬件情况下（扬声器等），5000毫安时的电池真是太耐用了，我从上班到下班，一直连着2~3个设备的情况下，还能剩下30+%的电量，确实很舒服。

看smzdm上的折腾里，能强解BL，但修补boot不能获取root权限，有点遗憾。原来还有想法搞个小猫咪上去，用root 后的VPN热点给一些设备爬墙来着。

（等网络好了之后再出掉吧）
